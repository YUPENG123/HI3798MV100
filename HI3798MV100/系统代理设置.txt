如果你的 hi3798mv100 刷了纯字符界面的 Ubuntu 系统，那玩法就完全不一样了！在这种没有图形界面的 Linux 终端环境下，让它通过电脑的 v2rayN 代理上网，有以下几种最简便、有效的方法。
既然你电脑的 v2rayN 已经开启了局域网共享，且 mix 端口为 10808，请先通过 SSH 连接到盒子的 Ubuntu，然后选择以下任意一种方式配置：
------------------------------
## 方法一：设置临时环境变量（适合临时下载、更新系统）
如果你只是偶尔需要用代理让盒子 apt update 升级系统、或者用 wget/curl 下载一个脚本，直接在终端输入以下三行命令即可（最安全，重启后自动失效）：

# 请将 192.168.1.X 替换为你电脑的实际局域网 IP
export http_proxy="http://192.168.1.X:10808"
export https_proxy="http://192.168.1.X:10808"
export all_proxy="socks5://192.168.1.X:10808"

测试是否成功：
输入以下命令，看返回的 IP 是否已经变成了你电脑代理节点的 IP：

curl -L myip.ipip.net# 或者
curl -i https://google.com

------------------------------
## 方法二：设置永久全局代理（适合盒子长期需要挂载外网）
如果你希望这台 Ubuntu 盒子每次开机、任何时候都默认走电脑的代理上网，可以把环境变量写入系统的配置文件中：

   1. 编辑系统的环境配置文件：
   
   sudo nano /etc/profile
   
   2. 键盘方向键拉到文件的最底部，添加以下两行（由于 v2rayN 的 mix 端口同时支持 http 和 socks5，这里统一写 http 即可）：
   
   export http_proxy="http://192.168.1.X:10808"
   export https_proxy="http://192.168.1.X:10808"
   
   3. 按 Ctrl + O 保存，按 Enter 确认，再按 Ctrl + X 退出编辑器。
   4. 让配置立即生效：
   
   source /etc/profile
   
   
------------------------------
## 方法三：仅让 apt 包管理器走代理（最推荐的服务器玩法）
很多刷了 Linux 的魔改盒子，用户只是希望它能顺利安装软件（解决 apt-get 报错卡死），但不希望其他本地流量也走代理。你可以单独为 apt 挂代理：

   1. 创建或编辑 apt 的代理配置文件：
   
   sudo nano /etc/apt/apt.conf.d/99proxy
   
   2. 在文件里粘贴以下内容（注意末尾有分号）：
   
   Acquire::http::Proxy "http://192.168.1.X:10808/";
   Acquire::https::Proxy "http://192.168.1.X:10808/";
   
   3. 保存并退出。此时你运行 sudo apt update 就会直接走电脑的加速通道，而不会影响盒子的其他网络。

------------------------------
## ⚠️ Ubuntu 终端环境下的避坑指南：

   1. Ping 命令是不走代理的：
   在 Linux 中，ping 命令使用的是 ICMP 协议，而无论是 http 代理还是 socks5 代理，都无法代理 ICMP 流量。所以当你配好代理后，去 ping google.com 依然会显示网络不通。请务必使用 curl -I https://google.com 这样的命令来测试网页代理是否成功。
   2. 电脑不能休眠：
   因为盒子完全依赖电脑上的 v2rayN 转发流量，所以当盒子在跑任务（比如下载、运行脚本）时，你的电脑千万不能锁屏休眠，否则盒子会瞬间断网。
